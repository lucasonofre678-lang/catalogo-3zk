PAINEL 3ZK 4.0 — CADASTRO COMPLETO DE PRODUTOS
=================================================

NOVAS FUNCOES

- Cadastrar produto ou linha nova sem editar JSON.
- Adicionar novas cores a produtos existentes.
- Criar automaticamente as chaves de estoque.
- Atualizar produtos-base.json e produtos.json.
- Atualizar automacao/mapeamento-olist.json.
- Importar varias cores colando linhas do Excel.
- Informar ID Olist, SKU, GTIN e descricao por cor.
- Adicionar varias fotos por cor.
- Converter fotos para WebP e criar pasta/nome corretos.
- Detectar produto, cor, chave e ID Olist duplicados.
- Salvar rascunho do formulario no navegador.
- Cadastrar pausado ate a revisao final.
- Desfazer um cadastro antes de salvar.

REGRA IMPORTANTE

Cada cor precisa do ID individual do produto/variacao na Olist.
Sem esse ID, o painel nao publica o cadastro porque a automacao exige
uma correspondencia exata entre todas as cores e o mapeamento da Olist.

INSTALACAO

1. No GitHub Desktop, use Fetch origin e Pull origin caso apareca.
2. Feche o painel antigo.
3. Extraia este ZIP diretamente em:
   C:\3ZK\catalogo-3zk
4. Escolha Substituir os arquivos no destino.
5. Abra:
   ferramentas-local\ABRIR-PAINEL-SEM-PYTHON.cmd
6. Selecione a pasta principal catalogo-3zk.

PRIMEIRO TESTE

Cadastre apenas um produto de teste ou uma nova cor, marque como pausado,
clique em Preparar cadastro, confira a aba Alteracoes e depois Salvar.
No GitHub Desktop devem aparecer alteracoes em:

- dados/produtos-base.json
- dados/produtos.json
- automacao/mapeamento-olist.json
- assets/fotos/... (quando houver fotos)
- dados/controle-catalogo.json (quando cadastrado pausado)

COMMIT SUGERIDO PARA INSTALAR O PAINEL

Atualiza Painel 3ZK com cadastro completo de produtos

DEPOIS DE CADASTRAR UM PRODUTO

1. Commit e Push origin.
2. Aguarde Sincronizar estoque Olist ficar verde.
3. Aguarde Publicar catalogo ficar verde.
4. Se cadastrou pausado, revise e reative no painel quando estiver pronto.
