CORRECAO DE ABERTURA DO PAINEL 3ZK
===================================

O arquivo de abertura anterior estava com uma marcacao invisivel de
codificacao no inicio. Em alguns computadores Windows isso impede ou
atrapalha a execucao do arquivo BAT.

INSTALACAO

1. Extraia este ZIP diretamente em:
   C:\3ZK\catalogo-3zk

2. Escolha:
   Substituir os arquivos no destino

3. Entre em:
   C:\3ZK\catalogo-3zk\ferramentas-local

4. Abra:
   ABRIR-PAINEL-3ZK.cmd

O arquivo CMD e o BAT fazem a mesma coisa. O CMD foi incluido como
alternativa mais confiavel no Windows.

O novo iniciador:
- verifica se esta dentro da pasta correta;
- mostra uma mensagem clara quando falta algum arquivo;
- tenta abrir com "py";
- tenta abrir com "python";
- abre o modo direto quando Python nao esta instalado;
- nao fecha silenciosamente quando ocorre um erro.
