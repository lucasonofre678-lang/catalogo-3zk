PAINEL 3ZK — ABERTURA SEM PYTHON
================================

O erro aconteceu porque o Windows encontrou o atalho da Microsoft Store
chamado "python", mas o Python verdadeiro nao esta instalado.

Esta correcao nao usa Python.

INSTALACAO

1. Extraia este ZIP diretamente em:
   C:\3ZK\catalogo-3zk

2. Escolha:
   Substituir os arquivos no destino

3. Abra:
   C:\3ZK\catalogo-3zk\ferramentas-local

4. Execute:
   ABRIR-PAINEL-SEM-PYTHON.cmd

5. No painel, clique em:
   Selecionar pasta

6. Escolha:
   C:\3ZK\catalogo-3zk

Use Google Chrome ou Microsoft Edge atualizado.

NAO FACA COMMIT antes de confirmar que o painel abriu, carregou os
produtos e conseguiu salvar uma pausa.
