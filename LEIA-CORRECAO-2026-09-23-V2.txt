CORREÇÃO DO CATÁLOGO 3ZK — 23/09/2026 — V2

PROBLEMA DE CARREGAMENTO CORRIGIDO

No Live Server, o site tentava usar dados/produtos-preview.json antes do
catálogo oficial. Um preview antigo, incompleto ou incompatível podia causar a
mensagem "Não foi possível carregar os produtos".

Agora o site sempre abre dados/produtos.json. O preview só é usado quando o
endereço contém explicitamente ?preview=1.

O identificador de versão do script também foi atualizado no index.html e no
produto.html para impedir que o navegador reutilize o JavaScript antigo.
